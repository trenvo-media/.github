## How we build

Our website, [trenvomedia.com](https://www.trenvomedia.com), is built with React 19, TypeScript, Vite static pre-rendering and Tailwind CSS v4.


- **Static-first:** every page is pre-rendered HTML, so it is fast, crawlable and readable without JavaScript.
- **Secure by default:** a per-page Content-Security-Policy and security headers on every route.
- **Accessible:** keyboard navigation, reduced-motion support and jsx-a11y linting on every change.
